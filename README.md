# 🎓 Student Grade Tracker

A simple console-based Java application that allows users to manage student grades and generate a summary report.

## 📌 Features

- Add student names and grades
- Store data using ArrayList
- Calculate:
  - Average score
  - Highest score
  - Lowest score
- Display all student records
- Console-based user interface

## 🛠 Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

## 📂 Project Structure

```
StudentGradeTracker/

```

## ▶️ How to Run

### Compile

```bash
javac StudentGradeTracker.java
```

### Run

```bash
java StudentGradeTracker
```
